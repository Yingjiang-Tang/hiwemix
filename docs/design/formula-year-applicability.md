# 配方适用年份方案

状态：已按确认规则实现并完成本地验证；生产迁移已执行并完成结构、数据及匿名权限核验，待发布应用。

业务依据：同一个颜色下，可能存在适用于不同车辆年份的多个配方。

## 现状

- 目前年份保存在颜色层，配方保存逻辑没有持久化年份。
- 搜索按颜色年份过滤后，会返回该颜色下的全部配方。
- 结果行将每个配方与颜色年份条目组合；配方卡片还可能优先显示旧变体的年份文案。
- 配方详情能切换同一颜色下的多个配方，因此只修改搜索结果或表单不足以保证年份一致。

## 确认规则

1. 保留颜色适用年份，作为颜色的总范围。
2. 配方增加两种年份设置：沿用颜色年份、自定义适用年份。自定义支持单年和区间，沿用现有年份条目的表达方式。
3. 自定义范围必须包含在颜色适用年份内；不能只比较颜色年份的最小值/最大值，颜色范围中的空档也不能被越过。超出时提示管理员先调整颜色年份。
4. 搜索指定车辆年份时，返回适用年份覆盖该年的配方。明确不匹配的配方不出现在该次检索的配方切换列表中。
5. 没有填写检索年份时，展示该颜色的所有配方，并逐个注明适用年份，不将每个配方复制到颜色的全部年份下。
6. 自定义范围命中的配方优先展示；沿用颜色年份的历史配方清楚标注来源，不把继承范围表现为已逐个核实过的配方年份。
7. 年份重叠本身不禁止。同一颜色可能同时有 1K/2K、不同工序或多个备选配方。相同颜色、体系与工序的范围重叠时显示非阻断提示，仍展示所有符合条件的备选项，不按版本号自动覆盖或替用户选择。

## 示例

颜色 C 的适用年份为 2018–2025，配方 A 自定义为 2018–2021，配方 B 自定义为 2022–2025。

| 检索条件 | 结果 |
|---|---|
| 颜色 C，2020 年 | 配方 A |
| 颜色 C，2024 年 | 配方 B |
| 颜色 C，2026 年 | 没有匹配年份的配方 |
| 颜色 C，未填年份 | A、B 均显示，各自注明年份 |

如果另有历史配方 C 尚未细分年份、仍沿用颜色的 2018–2025，它也可能与 2024 年匹配。需要明确标注“沿用颜色年份”，并由管理员确认是否应将其限定到更小范围；系统不能推断真实配方适用性。

## 表单与展示

- 配方表单恢复“适用年份”：新建必须主动选择沿用颜色年份或自定义，无默认选项；编辑读取原设置。自定义可添加多个单年/区间。
- 管理端配方列表显示年份，方便区分同颜色的多个配方。
- 搜索卡片、配方详情、打印及复制文本统一显示当前配方的实际适用年份；切换配方时同步更新年份，避免沿用上一配方的标签。
- 收藏按 ID 读取当前配方年份；完整 FormulaSnapshot 包含年份模式和自定义区间，对比保留该快照。旧快照缺少字段时沿用快照中的颜色年份。当前代码没有个人配方保存入口，不新增该产品功能；已有完整快照结构可保存新增字段。
- 已有明确范围的配方未覆盖某年份时，显示无匹配结果，不自动选择相邻年份配方。

## 数据保存与兼容

- 采用配方自己的年份关联记录，复用单年/区间结构；新增年份设置模式，使“沿用”和“自定义”含义明确。
- 配方主记录、年份设置及色母组件在同一事务保存；任一步失败整体回滚，避免配方与年份部分更新。
- 数据库新增字段/关联表属于增量迁移；不删除颜色年份、配方、色母组件，不重新生成配方 ID，不修改克重与比例。
- 历史配方默认按原有颜色年份处理。不存在可可靠回填的配方年份，不能用创建时间、版本号或 ID 猜测。
- 颜色年份后续缩小时，先列出会与现有自定义配方年份冲突的记录，阻止静默缩小或改写配方范围。
- 年份匹配与展示放在共同的规则模块中，由保存校验、检索与展示使用同一套语义。

## 验收场景

1. 保存自定义配方年份后刷新仍保留；单年、区间边界均正确。
2. 上述 A/B 示例的四种检索结果正确，详情切换不会出现不符合检索年份的配方。
3. 配方范围中有空档时，空档年份不匹配；多个年份区间不会造成同一配方重复展示。
4. 不同体系/工序的年份重叠可保留；同体系/工序的多个命中项都有清楚的年份与版本信息。
5. 沿用模式的历史配方继续可用，并有明确标识；不凭空为历史记录分配年份。
6. 颜色年份与配方范围冲突时有明确提示，不能默默清空或扩大配方年份。
7. 保存失败不丢失原年份或组件；已有收藏、个人配方与对比仍可打开。
8. 桌面与移动端的表单、检索、详情、打印和复制显示一致。
