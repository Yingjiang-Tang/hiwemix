# 色母官网链接发布与验证

2026-11-03：用户已执行生产数据库迁移；只读核验确认 `website_url` 可读取，现有 116 个色母中 97 个有官网链接、19 个未关联，已关联链接均符合官网域名规则。应用待发布。

## 上线顺序

1. 在目标 Supabase 项目的 SQL Editor 执行 `supabase-migrations/20261103000001_toner_website_url.sql`，再发布应用。脚本用事务新增可空字段 `toners.website_url`，仅按现有编号回填历史 97 个链接，不创建色母记录。
2. 查询 `SELECT code, trade_name, website_url FROM public.toners ORDER BY code;`，核对已有链接和近期新增色母。首次执行前后色母总数应一致；新色母若不在历史映射中，链接为空。
3. 管理员在 Toner → 管理色母 → 编辑中填写产品页网址、点击“打开验证”核对编号和名称，再保存。检查卡片新标签跳转、刷新持久化，以及清空保存后解除关联。新增色母也支持网址留空。

迁移只在字段首次创建时回填。重复执行不能恢复已解除的链接，也不覆盖手动修改。字段省略的旧版写请求保留现有链接；新界面会明确提交网址或 `null`。前台从数据库读取，不回退到静态映射。

链接仅允许 HTTPS 的 `hiwe.com` 和 `www.hiwe.com`，拒绝账号密码、非标准端口和其他域名。不同色母允许共用产品页。本版本不自动检测网页存在性或产品匹配情况，需人工打开核对。

## 本机验证

- `npm test`：校验链接格式、接口权限、旧客户端省略字段、解除关联、数据读写映射。
- `npm run typecheck`、`npm run build`：类型和生产构建。
- `npm run test:db-toners`、`npm run test:e2e:toners`：先设置 `TEST_DATABASE_URL`，指向本机测试 PostgreSQL 的管理数据库，例如 `postgresql://postgres@127.0.0.1:55439/postgres`。测试会另建独立数据库并在结束后删除，拒绝远程数据库地址。
- 浏览器测试使用真实 PostgreSQL 保存和读取，HTTP 层模拟 Supabase Auth 与 PostgREST，不使用生产账号或数据。覆盖 375/414/768/1024px、保存即时更新和刷新、清空关联、非法网址、未保存网址预览、请求失败保留输入、重试和防止重复提交。
- 可选桌面对比：将修改前页面作为本机临时路由运行，设置 `TONER_BASELINE_URL` 为该页面的完整地址。对比 768/1024px 下单分类和 All 的完整色母内容区域 PNG，要求像素一致；未提供基准页面时该项跳过。
